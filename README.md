# Oussama Ouslimane Portfolio

A modern, responsive portfolio website built with HTML, CSS, and Vanilla JavaScript.

## Features
- **Minimalist Design**: Clean white background with a subtle grid pattern.
- **Dynamic Accents**: Cyan lines and yellow highlights inspired by modern student portfolios.
- **Interactive Elements**: Scroll reveal animations, animated skill bars, and a typewriter effect.
- **Responsive Layout**: Optimized for desktop, tablet, and mobile devices.
- **Smooth Navigation**: One-page scrolling with a sticky navbar.

## Project Structure
- `index.html`: Main structure and content.
- `style.css`: Design system, layouts, and animations.
- `script.js`: Interactive functionality.

## How to Run Locally
1. **Option A (Simple)**: Open `index.html` directly in any web browser (Double-click the file).
2. **Option B (Recommended)**: Use a local server like XAMPP or VS Code's "Live Server" extension for better handling of assets and paths.
   - If using XAMPP: Place the folder in `C:\xampp\htdocs\` and access it via `http://localhost/folder-name`.

## How to Publish Online

### Method 1: GitHub Pages (Recommended for Students)
1. Create a new repository on GitHub (e.g., `my-portfolio`).
2. Upload your files (`index.html`, `style.css`, `script.js`) to the repository.
3. Go to **Settings** > **Pages**.
4. Under "Build and deployment", select the **Branch** as `main` and folder as `/ (root)`.
5. Click **Save**. GitHub will provide a link like `https://your-username.github.io/my-portfolio/`.

### Method 2: Netlify (Easiest)
1. Go to [Netlify](https://www.netlify.com/).
2. Drag and drop your project folder onto the Netlify dashboard.
3. It will instantly deploy your site and provide a public URL.

## Getting the Public URL for Lab Submission
- After following the steps above, copy the URL provided by GitHub or Netlify (e.g., `https://oussama-ouslimane.github.io/portfolio`).
- Test the URL in a private/incognito window to ensure it works for everyone.
